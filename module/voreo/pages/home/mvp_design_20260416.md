# MVP 设计文档：ThingTale

## 一、产品概述

### 1. 产品定位
拍照记录日常小物，AI 生成物品描述与分类标签的轻量工具。

### 2. 核心价值
- **快速归档**：为收藏品、手办、文具、摆件等日常物品生成结构化描述
- **智能分类**：自动识别物品类型并打上标签，便于后续检索
- **回忆陪伴**：为每件物品写一句"为什么拥有它"的回忆短文

### 3. 目标用户
| 用户类型 | 使用场景 |
|---------|---------|
| 收藏爱好者 | 手办、盲盒、模型、邮票等藏品记录 |
| 文具控 | 笔记本、钢笔、胶带等文具整理 |
| 生活记录者 | 咖啡杯、桌面摆件、旅行纪念品归档 |
| 极简主义者 | 物品盘点与断舍离前的记录 |

## 二、功能设计（MVP 范围）

### 1. 功能说明

#### 第 1 层：场景理解 (Scene Card)
AI 分析上传图片，提取以下信息：
| 字段 | 说明 | 示例 |
|-----|------|------|
| location | 场景位置 | 书桌 / 展示柜 / 旅行箱 |
| time | 时间推断 | 日常 / 收藏展示 / 打包中 |
| mood | 氛围感受 | 怀旧 / 整洁 / 收藏欲 |
| subjects | 物品识别 | 手办、咖啡杯、笔记本等 |
| colors | 主色调 | 暖色 / 冷色 / 彩色 |
| atmosphere | 整体气质 | 温馨 / 收藏感 / 创意 |

#### 第 2 层：核心内容生成
基于 Scene Card，生成以下内容：

**1. 物品描述**（3-5 句）
- 外观特征描述
- 材质与工艺观察
- 风格判断（复古、现代、手作等）

**2. 分类标签**（3-5 个）
- 类别标签（如：手办、文具、摆件）
- 风格标签（如：复古、极简、可爱）
- 场景标签（如：桌面、收藏、旅行纪念）

**3. 回忆短文**（1 句）
- 以"这让我想到..."开头，生成一段温柔的回忆文字
- 避免具体日期，强调感受与记忆

#### 第 3 层：基础功能
- **复制全文**：一键复制内容到剪贴板
- **保存到历史**：本地保存最近 50 条记录
- **重新生成**：对同一图片重新生成
- **删除记录**：删除不需要的历史记录
- **导出卡片**：生成可分享的图片卡片

### 2. 付费模式
- **免费次数**：新用户随机获得 1-3 次免费使用
- **单次生成**：每次生成消耗 50-100 金币（随机）

### 3. 页面结构（3 页）
| 页面 | 布局说明 |
|------|---------|
| Home | 上传按钮 + 最近物品缩略 + 金币余额 |
| Result | 物品图片 + Scene Card + 描述 + 标签 + 回忆短文 + 操作区 |
| History | 物品卡片列表 + 搜索 + 删除 |

### 4. 关键交互流程
```
拍照/选择图片 → 检查金币余额 → AI 分析 → 显示结果 → 可选保存/分享
```

## 三、IAP 设计

### 1. 商品配置
- 类型：Consumable（金币包）
- 触发：免费次数用完后
- 消耗：每次生成消耗 50-100 金币（随机）

### 2. 免费策略
- 新用户随机获得 1-3 次免费使用
- 免费次数用完后引导购买金币

> **注意**：金币包的具体配置（价格、数量、折扣等）由后续流程单独设计。

## 四、隐私与权限

### 1. 权限清单
| 权限 | 用途 | 申请时机 |
|-------|------|---------|
| NSCameraUsageDescription | 拍摄物品照片 | 用户点击拍照时 |
| NSPhotoLibraryUsageDescription | 从相册选择物品图片 | 用户点击上传时 |
| NSPhotoLibraryAddUsageDescription | 保存导出卡片到相册 | 用户点击保存时 |

### 2. iOS 权限文案
```xml
<!-- 相机 -->
<key>NSCameraUsageDescription</key>
<string>This app uses camera to capture photos of your items.</string>

<!-- 相册读取 -->
<key>NSPhotoLibraryUsageDescription</key>
<string>This app needs access to your photo library to import item images.</string>

<!-- 相册保存 -->
<key>NSPhotoLibraryAddUsageDescription</key>
<string>This app saves exported item cards to your photo library.</string>
```

### 3. 数据处理说明
| 数据类型 | 处理方式 | 保存策略 |
|---------|---------|----------|
| 用户上传的图片 | 上传云端 AI 分析 | 处理后立即删除 |
| Scene Card 数据 | 本地存储 | 设备本地，可清除 |
| 生成的内容 | 本地存储 | 设备本地，可清除 |
| 金币余额 | 本地 + Apple IAP | Apple 凭证加密 |

## 五、过审要点

### 过审避坑清单
- 免费版有完整价值（能生成描述和标签）
- 按次扣费清晰透明
- 不把"通用聊天"当唯一功能
- IAP 使用 Consumable 类型
- 文案不夸大（不承诺"专家级鉴定"）
- 提供清除数据功能
- AI 输出加"可能不准确"提示

### 特别注意
- 不做物品价值评估（避免经济纠纷）
- 不做真伪鉴定承诺
- 不做电商推荐链接
- 不做社区或交易功能
