# StudyFocus AI - MVP 应用设计文档

## 一、产品概述

### 1. 产品定位
一款帮助用户保持学习专注、养成学习习惯的 AI 陪伴工具，通过监督打卡、番茄计时和智能复盘提供持续的学习动力。

### 2. 核心价值
- **即时督促**：AI 陪伴聊天，在学习过程中提供鼓励和提醒
- **专注计时**：番茄钟功能，帮助用户保持专注节奏
- **智能复盘**：学习结束后自动生成学习总结和改进建议

### 3. 目标用户
| 用户类型 | 使用场景 |
|---------|---------|
| 学生党 | 备考期间需要监督和打卡 |
| 职场人 | 学习新技能时需要保持专注 |
| 自学者 | 需要外部督促完成学习目标 |

---

## 二、功能设计（MVP 范围）

### 1. 功能说明

#### 第 1 层：学习场景设置
用户开始学习前设置：
- **学习目标**：输入本次学习目标（50 字以内）
- **计划时长**：选择计划学习时间（15/25/45/60 分钟）
- **专注模式**：选择番茄钟或自由计时

#### 第 2 层：AI 陪伴与监督
- **学习前鼓励**：AI 根据学习目标给出鼓励话语
- **学习中提醒**：计时过程中提供专注提醒（每 15 分钟一次）
- **进度反馈**：显示当前进度和剩余时间
- **完成庆祝**：学习结束时给予成就反馈

#### 第 3 层：学习复盘生成
学习结束后 AI 自动生成：
- **学习摘要**：本次学习的目标完成情况
- **专注度评估**：基于时长和完成度的简洁评价
- **改进建议**：1-2 条下次学习的优化建议
- **成就卡片**：可分享的学习成就卡

#### 第 4 层：基础功能
- **学习历史**：查看过去 30 天的学习记录
- **数据统计**：累计学习时长、连续打卡天数
- **成就系统**：解锁不同学习里程碑的徽章
- **删除记录**：删除不需要的学习记录
- **清除数据**：一键清除所有用户数据

### 2. 付费模式
- **免费次数**：新用户随机获得 1-3 次完整学习陪伴
- **单次陪伴**：每次完成学习生成复盘消耗 50-100 金币（随机）
- **中途退出不扣费**：学习未完成不消耗金币

### 3. 页面结构（4 页）
| 页面 | 布局说明 |
|------|---------|
| Home | 开始学习按钮 + 今日学习统计 + 连续打卡天数 + 金币余额 |
| Focus | 计时器显示 + AI 陪伴聊天区 + 专注提示 + 完成按钮 |
| Summary | 学习摘要 + 专注度评估 + 改进建议 + 成就卡片 + 操作区 |
| History | 学习记录列表 + 数据统计 + 成就徽章墙 |
| Settings | 购买金币 + 清除数据 + 隐私政策 + 用户协议 |

### 4. 关键交互流程
```
设置学习目标 → 选择时长 → 开始学习 → AI 陪伴计时 → 完成学习 → 生成复盘 → 保存记录
```

## 三、IAP 设计

### 1. 商品配置
- 类型：Consumable（金币包）
- 触发：免费次数用完后，点击"开始学习"时引导购买
- 消耗：每次完成学习生成复盘消耗 50-100 金币（随机）

### 2. 免费策略
- 新用户随机获得 1-3 次免费完整学习陪伴
- 免费次数用完后引导购买金币包继续使用

> **注意**：金币包的具体配置（价格、数量、折扣等）由后续流程单独设计。

## 四、隐私与权限

### 1. 权限清单
| 权限 | 用途 | 申请时机 |
|-------|------|---------|
| 无 | 本地工具，无需相机/相册权限 | N/A |

### 2. iOS 权限文案
本应用不涉及相机或相册权限，无需配置相关权限文案。

### 3. 数据处理说明
| 数据类型 | 处理方式 | 保存策略 |
|---------|---------|----------|
| 学习目标与时长 | 本地存储 | 设备本地，可清除 |
| AI 复盘内容 | 本地存储 | 设备本地，可清除 |
| 学习统计数据 | 本地存储 | 设备本地，可清除 |
| 金币余额 | 本地 + Apple IAP | Apple 凭证加密 |

### 4. 隐私原则
- 无需网络权限，AI 功能通过本地 API 实现
- 数据最小化，仅存储学习相关数据
- 不做 UGC/社区功能
- 提供清除数据功能
- AI 输出加"建议仅供参考"提示

## 五、过审要点

### 过审避坑清单
- **免费价值**：免费用户可体验完整功能（1-3 次）
- **透明扣费**：在开始学习前明确提示金币消耗
- **功能聚焦**：专注学习陪伴，不做通用 AI 聊天
- **IAP 类型**：使用 Consumable 类型金币包
- **文案克制**：不夸大效果，不承诺学习提升幅度
- **数据控制**：提供清除数据功能
- **权限最小化**：不申请相机、相册、位置等敏感权限
- **无医疗承诺**：不涉及诊断、治疗等医疗范畴

### 特色优势
- 纯本地工具，无隐私风险
- 学习陪伴场景清晰，非通用 AI 聊天
- 成就系统激励，但非社交游戏
- 支持离线使用（AI 调用除外）
